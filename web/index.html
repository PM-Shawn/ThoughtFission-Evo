ThoughtFission 思维裂变引擎

将一个问题裂变为多个专家视角，通过协作、对抗、迭代产生深度洞察。

1 设计 — 主分析师设计调研团队

输入问题后，主分析师自动设计调研团队，为每位专家分配具体任务和方法论。

2 调研 — 专家并行执行任务

所有专家并行工作，可调用搜索工具获取实时信息，各自形成独立发现和置信度。

3 评判 — 主分析师评估结果质量

主分析师审查所有专家的发现，评估覆盖度和质量，决定是否需要补充调研。

4 进化 — 按需补充/重定向/移除专家

根据评判结果，主分析师可以：

  • 补充 (spawn) — 新增专家填补空白
  • 重定向 (redirect) — 调整专家分析方向
  • 移除 (drop) — 淘汰低质量专家

5 汇报 — 形成最终结论

汇总所有调研发现，形成最终结论。多轮迭代确保结论的深度和广度。

Agent 操作

左键点击已完成的 Agent 节点，详情卡片顶部显示操作按钮：

  • 深钻 (Deep Drill) — 对该 Agent 的发现进行二次裂变，子专家实时出现在画布上展开更细致的分析
  • 重定向 (Redirect) — 输入新的分析方向，该 Agent 按你的提示重新裂变，子专家同样实时展示在画布上
  • 移除 (Dismiss) — 将该 Agent 从画布上移除，不参与后续汇报
画布交互:
• 左键点击节点查看详情和操作按钮
• 滚轮缩放画布   • 拖拽节点调整布局   • 拖拽空白区域平移视角
